# Calculateur KBOB / KBOB Rechner — Pompes à chaleur (GitHub Pages)

Application web 100 % autonome (HTML / CSS / JavaScript) destinée à la plateforme **KBOB / ecobau**, développée par l'**Institut des Énergies (IE) de la HEIG-VD** et financée par l'**Office fédéral de l'énergie (OFEN)** dans le cadre du projet **LCA-PAC**.

## Test local

```bash
python -m http.server 8000
# Ouvrir http://localhost:8000
```
